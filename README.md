A game originally created in one week as an April Fools’ Day joke, which was later updated over the course of another week as part of the Brackeys Game Jam 2026.2 with the theme “Trust No One.” At the game jam, out of more than 2200 games, it took 15th place Overall, as well as 10th place in the Enjoyment category and 8th place in the Innovation category. 

Here is a link to the game on itch.io, where you can also visit the game’s page from the game jam: https://nik-nik-75.itch.io/free-cheese-in-a-lovetrap


This game only requires a mouse
